# オンライン大富豪

`大富豪_要件仕様書_v1.1.md` に基づく、最大7人対戦のオンライン大富豪Webアプリです。
Node.js + Express + Socket.IO のサーバーと、ビルド不要のバニラJSクライアント（スマートフォン縦画面向け）で構成されています。

## 起動方法

```bash
npm install
npm start
```

起動後、ブラウザで `http://localhost:3000` を開いてください（`PORT` 環境変数で変更可能）。
同一LAN内の他端末からは `http://<サーバーのIPアドレス>:3000` でアクセスできます。

## 遊び方

1. 1人がルームを作成し、発行された合言葉（6桁のルームID）を他のプレイヤーに共有する。
2. 他のプレイヤーは名前とルームIDを入力して参加する。
3. 2人以上集まったらルームオーナーが「ゲーム開始」を押す。
4. ゲーム終了後は同じルームで「もう一度プレイ」から再戦できる。

## 実装済みルール

基本ルール（強さ、ターン進行、流れ判定）に加えて、以下の特殊ルールをすべてサーバー側で判定・管理しています。

- 8切り／Jバック／革命／階段／階段革命／スペ3返し／Qボンバー／7わたし／10捨て／マーク縛り
- 禁止カード（8・J・ジョーカー・♠3・最強カード）での上がりに対する反則負け判定
- 同時上がりの同順位処理、離脱・反則の発生順による下位順位の割り当て
- ターン（1分）／Qボンバー選択（1分）／7わたし選択（1分）のタイムアウトと自動処理
- 60秒の再接続猶予とBot化（自動パス）

ゲーム状態（手札・場・革命・Jバック・縛り・順位など）はすべてサーバー側の `server/game/Game.js` が管理し、クライアントは表示と操作入力のみを行います（仕様書12章準拠）。

## 実装上の補足（仕様上あいまいな箇所への解釈）

- **マーク縛りの進行**: 直前の役と今回の役のスート集合の共通部分を都度取り、「必須スート集合」を単調に確定・拡大させる方式で実装しています（仕様書の例1・例2の挙動と一致することを確認済み）。
- **Qボンバー／7わたし／10捨てによる0枚化**: 仕様書の指示どおり、反則判定・各種特殊効果の再発動対象外としています（直接プレイで手札を0にした場合のみ反則判定を行います）。10捨てで残り手札が出した10の枚数より少ない場合は、残り全部を捨てれば良い仕様どおりに枚数を自動調整します。
- **切断からのBot化**: 簡易的に「出せる場合は自動パス、場が空なら最弱の単騎を自動で出す」という動作にしています（高度なAI戦略は実装していません）。
- **階段でのジョーカー割り当て**: 内部の欠番を優先して埋め、余ったジョーカーは上位側に延長する形で階段を成立させています。

## 動作確認

- `server/game/Game.js` のみを対象に、2〜7人でのランダムプレイを多数回自動実行し、フリーズ・クラッシュがないことを確認済みです。
- Socket.IO経由でのルーム作成〜参加〜ゲーム開始〜特殊効果解決〜ゲーム終了までの一連の通信も自動テストで確認済みです。

## ディレクトリ構成

```
server/
  index.js          Express + Socket.IO エントリーポイント
  roomManager.js     ルーム（ロビー）管理
  game/
    cards.js          カード定義・強さ計算
    handEvaluator.js   役判定（単体/複数/階段）
    Game.js            ゲーム進行の中核ロジック
public/
  index.html / style.css / main.js   クライアント（モバイル縦画面UI）
```
