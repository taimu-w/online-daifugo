# オンライン大富豪

`大富豪_要件仕様書_v1.1.md` に基づく、最大7人対戦のオンライン大富豪Webアプリです。
Node.js + Express + Socket.IO のサーバーと、ビルド不要のバニラJSクライアント（スマートフォン縦画面・横画面・PC対応、PWA対応）で構成されています。

## セットアップ・起動方法

```bash
npm install
npm start
```

起動後、ブラウザで `http://localhost:3000` を開いてください（`PORT` 環境変数で変更可能）。
同一LAN内の他端末からは `http://<サーバーのIPアドレス>:3000` でアクセスできます。

### PWA（ホーム画面に追加）

`public/manifest.webmanifest` と `public/sw.js`（サービスワーカー）により、Android・iOSともにホーム画面に追加してアプリのように全画面で起動できます。

- **Android（Chrome等）**: ホーム画面の「📲 アプリとしてインストール」ボタン、またはブラウザメニューの「アプリをインストール」から追加。
- **iOS（Safari）**: 共有ボタン →「ホーム画面に追加」（Safariで開いているときはホーム画面に案内が表示されます）。
- PWAのインストールには **HTTPS での配信が必須** です（`localhost` のみ例外）。LAN内の `http://<IP>:3000` ではホーム画面に追加してもブラウザのショートカット扱いになります。
- 対戦はリアルタイム通信が前提のため、オフラインでは遊べません。サービスワーカーは常にネットワーク優先で、画面の外枠を素早く表示する目的でのみキャッシュします。`public/` の静的ファイルを変更したら `sw.js` の `CACHE_NAME` のバージョンを上げてください。
- アイコン画像は `public/icons/` にあります。

ビルドステップは無く（バニラJS配信のみ）、`npm start` と `npm run dev` は同一（`node server/index.js`）です。

## 遊び方

1. 1人がルームを作成し、発行された合言葉（6桁のルームID）を他のプレイヤーに共有する。
2. 他のプレイヤーは名前とルームIDを入力して参加する。
3. 2人以上集まったらルームオーナーが「ゲーム開始」を押す。
4. ゲーム終了後は同じルームで「もう一度プレイ」から再戦できる。

## 実装済みルール

基本ルール（強さ、ターン進行、流れ判定）に加えて、以下の特殊ルールをすべてサーバー側で判定・管理しています。

- 8切り／Jバック／革命／階段／階段革命／スペ3返し／Qボンバー／7わたし／10捨て／マーク縛り
- 禁止カード（8・J・ジョーカー・最強カード）での上がり、およびスペ3返しでの上がりに対する反則負け判定（♠3は常に禁止ではなく、ジョーカー単体へのスペ3返しで上がった場合のみ反則）
- 7わたし・階級制のカード交換で渡したカードの内容は当事者（渡した人・受け取った人）にのみ表示し、他のプレイヤーには枚数のみ表示
- 同時上がりの同順位処理、離脱・反則の発生順による下位順位の割り当て
- ターン（1分）／Qボンバー選択（1分）／7わたし選択（1分）／10捨て選択（1分）のタイムアウトと自動処理
- 60秒の再接続猶予とBot化（自動パス）

ゲーム状態（手札・場・革命・Jバック・縛り・順位など）はすべてサーバー側の `server/game/Game.js` が管理し、クライアントは表示と操作入力のみを行います（仕様書12章準拠）。処理の詳細は [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) を参照してください。

> **10捨てについて**: 要件仕様書 v1.1 には明記されていませんが、実装済みのローカルルール拡張です。仕様変更時は仕様書とこのREADME・docsの整合を保ってください。

### 画面レイアウト

- **スマホ縦向き**: 上にプレイヤー一覧、中央に場、下に手札。手札が1行に収まらないとき（2〜3人対戦など）は重ならない2段に自動で折り返し、横スクロールなしで全カードが見えます。カードを選ぶと選んだカードだけが少し持ち上がり、他のカードの位置は動きません。
- **スマホ横向き**: 左にプレイヤー一覧、右に場、下に手札。「出す」「パス」は手札の右側に並び、場や手札に被りません。ノッチ（セーフエリア）にも対応。
- **タブレット・PC**: 手札・場を大きめに表示。PCではキーボード操作（Enter=出す / P=パス / Esc=選択解除）も可能。
- 7わたし・10捨て・カード交換の選択画面は、手札エリアに重ならないよう中央エリア内のパネルとして表示します（手札をタップして選択／選び直し、7わたしは相手の名前をタップして指定）。

### 連続対戦オプション: 階級制・都落ち（要件仕様書 v1.1 には未記載のローカルルール拡張）

ルームオーナーがロビー画面でいつでもオン/オフできる、複数戦にまたがるオプションです（ゲーム中は変更不可）。

- **階級制**: 前回のゲーム結果（1位〜最下位）を引き継ぎ、次のゲーム開始時に「献上・下賜」のカード交換を行います。
  - 人数に応じて階級を割り当てます：2〜3人なら 大富豪／(平民)／大貧民、4人以上なら 大富豪／富豪／(平民)／貧民／大貧民。
  - 大貧民は最強のカード2枚を大富豪へ、貧民は最強のカード1枚を富豪へ、**強制的に**献上します（選択の余地なし）。
  - 大富豪・富豪は受け取った手札から**返すカードをプレイヤー自身が選んで**下賜します（返す枚数は献上と同数が基本）。
  - 献上・下賜されたカードの内容は、交換した2人にだけ表示されます（他のプレイヤーには枚数のみ）。
  - 交換後は前回の大貧民から先手が始まります。
  - 直前のゲームと参加メンバーが完全に一致しない場合（誰か抜けた/新しく入った）は、階級を引き継がず通常開始（♠3持ちが先手）になります。
- **都落ち**: 階級制がオンのときのみ有効なオプション。前回**大富豪**だったプレイヤーが今回**大貧民**に転落した場合、次のゲームでの献上枚数が2枚ではなく**3枚**に増えます（大富豪からの下賜は通常どおり2枚のまま）。富豪⇔貧民間の交換には影響しません。

仕様変更時は仕様書とこのREADME・docsの整合を保ってください。

## 実装上の補足（仕様上あいまいな箇所への解釈）

- **マーク縛りの進行**: 直前の役と今回の役のスート集合の共通部分を都度取り、「必須スート集合」を単調に確定・拡大させる方式で実装しています（仕様書の例1・例2の挙動と一致することを確認済み）。
- **Qボンバー／7わたし／10捨てによる0枚化**: 仕様書の指示どおり、反則判定・各種特殊効果の再発動対象外としています（直接プレイで手札を0にした場合のみ反則判定を行います）。10捨てで残り手札が出した10の枚数より少ない場合は、残り全部を捨てれば良い仕様どおりに枚数を自動調整します。
- **切断からのBot化**: 簡易的に「出せる場合は自動パス、場が空なら最弱の単騎を自動で出す」という動作にしています（高度なAI戦略は実装していません）。
- **階段でのジョーカー割り当て**: 内部の欠番を優先して埋め、余ったジョーカーは上位側に延長する形で階段を成立させています（複数の延長方向が有効な場合はクライアントに選択させます。[docs/SOCKET_API.md](docs/SOCKET_API.md) の `game:needsChoice` 参照）。

## 動作確認

- `server/game/Game.js` のみを対象に、2〜7人でのランダムプレイを多数回自動実行し、フリーズ・クラッシュがないことを確認済みです。
- Socket.IO経由でのルーム作成〜参加〜ゲーム開始〜特殊効果解決〜ゲーム終了までの一連の通信も自動テストで確認済みです。

上記の確認は開発時に一時スクリプトで実施したもので、リポジトリにテストコードとしては含まれていません（現状 `npm test` に相当するコマンド・テストスイートは未整備です）。今後ロジックを変更する際は、同種のランダムプレイ検証スクリプトの追加を検討してください。
